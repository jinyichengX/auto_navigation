三个 TF 变换

map → odom（漂移补偿）
x:0.00 y:0.00 θ:0.0°
odom → base（里程计读数）
x:0.00 y:0.00 θ:0.0°
map → base（组合结果）
x:0.00 y:0.00 θ:0.0°

控制

鼠标拖拽旋转 | 滚轮缩放 | 右键平移
W前 S后 A左移 D右移 Q左转 E右转
map 是绝对世界坐标系，固定不动。
odom 原点本应在起点，但里程计（编码器）每次读数都多走一点，误差累积后 odom 轴逐渐偏离 map 轴。
base_footprint 是机器人真实位置。

TF 树只有两条边：map → odom 和 odom → base。
map → base 是这两条组合出来的结果，不是独立发布的 TF。

map → odom 就是漂移量，SLAM 每隔 10 秒修正一次，把 odom 拉回 map 原点。
